## Trust strategy

Use transparency instead of manufactured social proof: explain services, prices, intake sequence, turnaround qualifiers, pickup/delivery threshold and unavailable contact status. Keep the preview notice persistent. All rows remain DEMO-ONLY / NOT_APPROVED and this register is not a public proof pack.
