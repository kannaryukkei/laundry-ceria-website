## Content hierarchy

1. User question and clear section heading.
2. Exact source-backed answer.
3. Unit, condition or qualifier directly beside the answer.
4. Demo/publication disclosure where it affects interpretation.
5. Missing information represented as unavailable, not silently omitted where the absence matters.

## Evidence model

The source fixture remains authoritative for business facts. Stage 1–3 project handoffs are derived planning documents; they cannot add new facts or approve real publication.
